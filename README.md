# VICON Studios

Premium editorial portfolio website for **VICON Studios** — an independent multidisciplinary creative studio based in Lusaka.

> **Jump In Our World.**

## Features

- Immersive animated hero with rotating VICON artwork
- Interactive creative-world cards and service overlays
- Horizontal-scrolling project showcase
- Project case-study overlays
- Illustrated process, testimonials and contact experience
- Magnetic controls, custom cursor, parallax and reveal animations
- Fully responsive desktop and mobile layouts
- Self-hosted fonts and optimized WebP imagery

## Run locally

This is a dependency-free static website. Start any local web server from the project directory:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
